Step 4 of 10 — Security Groups & Access

Step 4 — Security Groups

🎯 What

Configure firewall rules for your EC2 instance.

🎥 Learn

▶ AWS Security Groups Explained

🧠 Why this matters

Security groups control who can access your server. Wrong config = app not accessible OR security risk.

🪜 Setup Rules

SSH (22) → Your IP only
HTTP (80) → 0.0.0.0/0
Custom (8000) → 0.0.0.0/0

⚠️ Important

  • Never open SSH to entire internet in production
  • Limit access to your IP

🪜 Apply Changes

  • Go to EC2 → Security Groups
  • Edit inbound rules
  • Add required ports

✅ Verify

  • Backend accessible on browser
  • No connection timeout

🚦 Checklist

  • ✔ Ports configured
  • ✔ Backend reachable
  • ✔ SSH secure
