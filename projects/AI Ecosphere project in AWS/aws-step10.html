Step 10 — Final Validation & Testing

🎥 Learn This Concept

▶ Backend Testing & Debugging

Understand how real systems are tested and debugged

🎯 What are we doing?

Validate your complete AI system end-to-end: Frontend → API Gateway → Backend → RAG → Response

🧠 Why is this needed?

A working system is not enough — it must:

  • Handle real user queries
  • Return correct responses
  • Recover from failures

🪜 Steps

1. Test API directly

curl "http://EC2-IP/query?q=What is EC2?"

✔ Expect JSON response with correct answer

2. Test via API Gateway

curl "https://your-api-url/query?q=What is EC2?"

✔ Confirms routing works

3. Test frontend

  • Open S3 website URL
  • Enter query
  • Click Send

✔ Response appears on UI

4. Validate RAG accuracy

What is EC2?
What is S3?

✔ Answers must match your data

5. Negative testing

Who is king of Mars?

✔ Should NOT hallucinate

6. Load testing

for i in {1..10}; do curl "http://EC2-IP/query?q=test" & done

✔ System should not crash

7. Failure testing

sudo systemctl stop ai-app
sudo systemctl start ai-app

✔ System should recover automatically

⚙️ How this fits in system

User → S3 → API Gateway → Nginx → Gunicorn → FastAPI → RAG → Response

🚦 Before Next Step

  • ✔ API working
  • ✔ Frontend connected
  • ✔ RAG accurate
  • ✔ Handles multiple requests
  • ✔ Recovers from failures

🎉 Your AI system is fully validated
