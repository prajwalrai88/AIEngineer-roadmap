Step 8 — RAG API

🎥 Learn First

▶ RAG Pipeline

🎯 Goal

Use your vector database and LLM to answer questions via API.

🪜 Step 1 — Make sure backend file exists

Your file should be:

app.py

🪜 Step 2 — Run your API server

uvicorn app:app --host 0.0.0.0 --port 8000

✔ Server should start without errors

🪜 Step 3 — Get your EC2 Public IP

  • Go to AWS Console → EC2
  • Select your instance
  • Copy Public IPv4 address

Example:

3.110.45.210

🪜 Step 4 — Test your API

Use this format:

http://YOUR-EC2-IP:8000/query?q=YOUR-QUESTION

Example:

http://3.110.45.210:8000/query?q=What is EC2?
  • Replace YOUR-EC2-IP with your IP
  • Replace YOUR-QUESTION with your query

✔ You should see JSON response

🧠 Explanation

  • Query → converted into embedding
  • FAISS → finds relevant data
  • LLM → generates answer
  • API → exposes this to frontend

🚦 Checklist

  • ✔ API running
  • ✔ EC2 IP working
  • ✔ Query returns correct response
