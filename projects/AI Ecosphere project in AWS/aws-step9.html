Step 9 — Make YOUR AI System Production Ready

🎥 Learn First

▶ FastAPI Production Deployment (Gunicorn + Nginx)

🎯 Goal

Run your existing RAG API (/query endpoint) as a stable, always-on production service.

---

🪜 Step 1 — Install Dependencies

pip3 install gunicorn
sudo apt install nginx -y

✔ Required tools installed

---

🪜 Step 2 — Run Your Existing App with Gunicorn

Your file: app.py

gunicorn -w 2 -k uvicorn.workers.UvicornWorker app:app --bind 127.0.0.1:8000

🧠 Explanation

  • Runs FastAPI app in production mode
  • 2 workers = handles multiple users
  • Binds locally (Nginx will expose it)
---

🪜 Step 3 — Configure Nginx

sudo nano /etc/nginx/sites-available/default

server {
    listen 80;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

sudo systemctl restart nginx

🧠 What this does

  • Nginx receives traffic from API Gateway
  • Forwards to Gunicorn
  • Improves reliability
---

🪜 Step 4 — Create systemd Service

sudo nano /etc/systemd/system/ai-app.service

[Unit]
Description=AI RAG App
After=network.target

[Service]
User=ubuntu
WorkingDirectory=/home/ubuntu
ExecStart=/usr/bin/gunicorn -w 2 -k uvicorn.workers.UvicornWorker app:app --bind 127.0.0.1:8000
Restart=always

[Install]
WantedBy=multi-user.target

sudo systemctl daemon-reexec
sudo systemctl start ai-app
sudo systemctl enable ai-app

✔ App auto-starts on reboot

---

🪜 Step 5 — Verify API

http://EC2-IP/query?q=What is EC2?

✔ Should return AI response

---

🪜 Step 6 — Update API Gateway

Ensure integration URL points to:

http://EC2-IP/query

✔ Frontend → API Gateway → Nginx → FastAPI working

---

🪜 Step 7 — Optimize RAG for Production

  • Limit retrieval results (k=2 or 3)
  • Keep context small
  • Avoid large prompts
---

🧠 Final Architecture

User → S3 → API Gateway → Nginx → Gunicorn → FastAPI (/query) → FAISS → LLM
---

❌ Common Issues

  • 502 error → Gunicorn not running
  • No response → wrong API Gateway URL
  • Slow response → large context
---

🚦 Checklist

  • ✔ Gunicorn running
  • ✔ Nginx working
  • ✔ systemd enabled
  • ✔ API reachable via browser
  • ✔ Frontend integrated

✔ Your AI system is now production-ready
