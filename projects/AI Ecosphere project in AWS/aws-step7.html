▶ Embeddings + FAISS

🎯 Goal

Convert your data into embeddings and store them in a vector database (FAISS) so that we can perform semantic search in the next step.

2. Create embedding script

nano embed.py

import numpy as np
import faiss
import pickle
from openai import OpenAI

client = OpenAI()

# Load data
with open("data.txt") as f:
    docs = [line.strip() for line in f.readlines()]

# Chunking function
def chunk_text(text, size=200):
    return [text[i:i+size] for i in range(0, len(text), size)]

chunks = []
for doc in docs:
    chunks.extend(chunk_text(doc))

# Create embeddings
embeddings = []
for chunk in chunks:
    res = client.embeddings.create(
        model="text-embedding-3-small",
        input=chunk
    )
    embeddings.append(res.data[0].embedding)

# Convert to numpy
emb_np = np.array(embeddings).astype("float32")

# Create FAISS index
index = faiss.IndexFlatL2(len(emb_np[0]))
index.add(emb_np)

# Create mapping
docstore = {i: chunk for i, chunk in enumerate(chunks)}

# Save
faiss.write_index(index, "vector.index")
pickle.dump(docstore, open("docstore.pkl", "wb"))

print("Vector DB created successfully")
---

3. Run the script

python3 embed.py

Expected output:

  • File created → vector.index
  • File created → docstore.pkl

🧠 Explanation

  • chunk_text() → splits large text into smaller pieces for better accuracy
  • embeddings → converts text into numerical vectors
  • FAISS → stores vectors for fast similarity search
  • docstore → maps vectors back to original text
  • vector.index → saved vector database
