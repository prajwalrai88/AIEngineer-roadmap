Step 1 — AWS Setup (IAM)

🎯 What

Setup AWS account and IAM user for secure access.

🎥 Learn

▶ AWS IAM Tutorial

🪜 Steps

  • Create AWS account
  • Go to IAM → Users
  • Create user: ai-ecosphere-user
  • Attach AdministratorAccess

⚠️ Important

Do NOT use root account in real projects.

🚦 Checklist

  • ✔ Account created
  • ✔ IAM user created
  • ✔ Keys saved
