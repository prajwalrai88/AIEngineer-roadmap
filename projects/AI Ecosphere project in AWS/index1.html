AWS AI Ecosphere — Enterprise Track

Build a production-grade AI system using AWS native infrastructure (EC2, S3, IAM, etc.) — no external hosting platforms.

What You Will Build

  • Upload documents to S3
  • Process via ingestion pipeline on EC2
  • Create embeddings and store in a vector database (pgvector)
  • Serve queries via FastAPI backend
  • Expose via domain (Nginx)
  • Basic CI/CD + monitoring

Architecture (Simple View)

User → Frontend → Nginx → FastAPI (EC2) → Ingestion/LLM → S3 + Vector DB → Response

Prerequisites

  • AWS account with billing enabled
  • Basic Linux command familiarity
  • SSH client (terminal)
  • Git installed
  • OpenAI API key (or alternative LLM)

How to Use This Track

  3. Mark each step complete
  4. Validate before moving next
