Step 6 — API Gateway Integration

🎥 Learn First

▶ API Gateway Integration

🎯 Goal

Connect your frontend (S3) with your backend (EC2 FastAPI server) using API Gateway.

🪜 Step 1 — Get Your EC2 Public IP

  • Go to AWS Console
  • Click EC2
  • Click Instances
  • Select your instance
  • Find Public IPv4 address

Example:

3.110.45.210

⚠ You will use YOUR IP in all steps below

🪜 Step 2 — Make Sure Backend is Running

Connect to your EC2 instance and run:

uvicorn app:app --host 0.0.0.0 --port 8000

✔ Your API server should now be running

🪜 Step 3 — Open Port 8000 (IMPORTANT)

  • Go to EC2 → Security Groups
  • Select your instance security group
  • Edit inbound rules
  • Add rule:
Type: Custom TCP
Port: 8000
Source: Anywhere (0.0.0.0/0)

⚠ Without this, your API will NOT be accessible

🪜 Step 4 — Test Backend Directly

Open browser or terminal:

http://YOUR-EC2-IP:8000/query?q=test

Example:

http://3.110.45.210:8000/query?q=test

✔ You should see a JSON response

🪜 Step 5 — Create API Gateway

  • Go to AWS Console → API Gateway
  • Click Create API
  • Select HTTP API
  • Click Build

🪜 Step 6 — Add Integration

Use your EC2 backend URL:

http://YOUR-EC2-IP:8000/query

Replace YOUR-EC2-IP with your actual IP

🪜 Step 7 — Configure Route

  • Route path: /query
  • Method: GET

🪜 Step 8 — Deploy API

  • Click Deploy
  • Copy the generated API URL

Example:

https://abc123.execute-api.ap-south-1.amazonaws.com/query

🪜 Step 9 — Test API Gateway

https://YOUR-API-URL/query?q=test

✔ Should return same response as EC2

🧠 Explanation

  • EC2 IP → your backend server
  • Port 8000 → where FastAPI runs
  • /query → your API endpoint
  • API Gateway → acts as public entry point

🚦 Checklist

  • ✔ Backend running
  • ✔ Port 8000 open
  • ✔ EC2 API working
  • ✔ API Gateway working

✔ Frontend can now connect to backend
