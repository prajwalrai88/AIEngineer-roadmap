Step 2 — EC2 Setup

🎯 What are we doing?

Creating a virtual server to run backend + AI pipeline.

🎥 Learn

▶ AWS EC2 Full Setup Tutorial
  • EC2 basics
  • Instance creation

🪜 Launch Instance

  • Go to EC2 → Launch Instance
  • Name: ai-ecosphere-server
  • AMI: Ubuntu
  • Type: t2.micro

🪜 Key Pair

  • Create new key pair
  • Download .pem file

⚠ Never lose this file

🪜 Security Group

SSH (22)
HTTP (80)
Custom (8000)

🪜 SSH Login

chmod 400 key.pem
ssh -i key.pem ubuntu@PUBLIC_IP

🚦 Checklist

  • ✔ EC2 running
  • ✔ SSH connected
  • ✔ Ports open
