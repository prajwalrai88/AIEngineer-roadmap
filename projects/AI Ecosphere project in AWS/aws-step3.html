Step 3 — Backend on EC2

🎯 What

Setup FastAPI backend on EC2 instance.

🎥 Learn

▶ Deploy Backend on EC2 (Updated)

🪜 Install Python

sudo apt update
sudo apt install python3-pip -y

🪜 Install FastAPI

pip3 install fastapi uvicorn

🪜 Create App

nano app.py

from fastapi import FastAPI
app = FastAPI()

@app.get("/")
def home():
    return {"status": "running"}

🪜 Run Server

uvicorn app:app --host 0.0.0.0 --port 8000

🌐 Access

http://PUBLIC_IP:8000

✔ Backend live

❌ Common Errors

  • Port blocked → security group issue
  • Server not running
  • Wrong IP

🚦 Checklist

  • ✔ Backend running
  • ✔ Accessible via browser
