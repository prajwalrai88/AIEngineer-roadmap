Step 3 — Deploy RAG App (CRITICAL STEP)

🧠 Step 0 — Project Structure (MANDATORY)

Where

  • Your LOCAL machine

Create folder

aws-ai-ecosphere-prod/

Inside this folder create:

app.py
requirements.txt
Dockerfile
deployment.yaml
service.yaml

✔ All work will happen inside this folder

🪜 Step 1 — Create app.py

from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {"message": "RAG App Running"}

🪜 Step 2 — Create requirements.txt

fastapi
uvicorn

🪜 Step 3 — Create Dockerfile

FROM python:3.10

WORKDIR /app

COPY requirements.txt .
RUN pip install -r requirements.txt

COPY . .

CMD ["uvicorn", "app:app", "--host", "0.0.0.0", "--port", "8000"]

🪜 Step 4 — Build Docker Image

Where

  • Open terminal
  • Navigate into project folder
cd aws-ai-ecosphere-prod

Run

docker build -t YOUR_DOCKERHUB_USERNAME/rag-app .

Example

docker build -t prajwalrai/rag-app .

Validation

docker images
Expected: 
rag-app   latest

🪜 Step 5 — Push Image to DockerHub

Login

docker login

Push

docker push YOUR_DOCKERHUB_USERNAME/rag-app

Validation

  • Go to DockerHub
  • Confirm image exists

✔ Image available for Kubernetes

🪜 Step 6 — Create deployment.yaml

apiVersion: apps/v1
kind: Deployment
metadata:
  name: rag-app
spec:
  replicas: 2
  selector:
    matchLabels:
      app: rag
  template:
    metadata:
      labels:
        app: rag
    spec:
      containers:
      - name: rag-container
        image: YOUR_DOCKERHUB_USERNAME/rag-app:latest
        ports:
        - containerPort: 8000

🪜 Step 7 — Create service.yaml

apiVersion: v1
kind: Service
metadata:
  name: rag-service
spec:
  type: ClusterIP
  selector:
    app: rag
  ports:
    - port: 80
      targetPort: 8000

🪜 Step 8 — Deploy to Kubernetes

Where

  • Terminal (same folder)
kubectl apply -f deployment.yaml
kubectl apply -f service.yaml

🪜 Step 9 — Validate Deployment

Check pods

kubectl get pods
Expected: 
rag-app-xxxx   Running
---

Check service

kubectl get svc
Expected: 
rag-service   ClusterIP

✔ Application deployed successfully

🧠 What just happened?

Code → Docker Image → DockerHub → Kubernetes → Running Pods

You containerized your app and deployed it to EKS.
