Step 2 — Create EKS Cluster

🧠 What this step does

EKS = Managed Kubernetes on AWS

This step creates your Kubernetes cluster where your application will run.

🪜 Step 1 — Create Cluster

Where: Local terminal

eksctl create cluster \ --name ai-ecosphere-cluster \ --region ap-south-1 \ --nodes 2

This takes ~10–15 minutes.

✔ Cluster created

🪜 Step 2 — Connect to Cluster (VERY IMPORTANT)

Where: Local terminal

aws eks update-kubeconfig \ --region ap-south-1 \ --name ai-ecosphere-cluster

This command connects your local machine to your EKS cluster. Without this, kubectl commands will not work.

🪜 Step 3 — Verify Connection

kubectl get nodes

Expected:

ip-xxx Ready ip-yyy Ready

✔ Cluster is ready

🪜 Step 4 — Check Pods

kubectl get pods -A

You should see system pods running.

🧠 What just happened

You created:
✔ Kubernetes control plane (managed by AWS)
✔ Worker nodes (EC2 instances)
✔ Networking + security

🧠 If command fails

  • Check AWS CLI:
    aws sts get-caller-identity
  • Check kubectl:
    kubectl version --client
  • Check region mismatch
