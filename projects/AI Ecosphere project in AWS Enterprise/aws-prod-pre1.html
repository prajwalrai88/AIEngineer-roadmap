P1 — AWS CLI Setup

🪜 Install

# Linux / Mac
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o awscliv2.zip
unzip awscliv2.zip
sudo ./aws/install

🪜 Configure

aws configure
Enter: - Access Key - Secret Key - Region (ap-south-1) - Output: json

🪜 Validate

aws sts get-caller-identity
✔ Should return your account details
