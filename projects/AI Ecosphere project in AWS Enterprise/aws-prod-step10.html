Step 10 — Final Validation + Testing

🧠 What you are validating

User → API Gateway → ALB → Kubernetes → Response

We will verify that your complete system is working end-to-end.

🪜 Step 1 — Get API Endpoint

Where:

  • AWS Console → API Gateway
  • Select your API
  • Look at top → Invoke URL

Example:

https://abc123xyz.execute-api.ap-south-1.amazonaws.com

✔ Copy this URL

🪜 Step 2 — Test Health API

https://YOUR-INVOKE-URL/health

Expected:

{"status":"ok"}

🪜 Step 3 — Test Query API

https://YOUR-INVOKE-URL/query?q=What is AWS?

Expected:

Valid response from system

🪜 Step 4 — Test Authentication

Without token:

curl https://YOUR-INVOKE-URL/query?q=test

Expected:

401 Unauthorized

With token:

curl -H "Authorization: Bearer YOUR_ID_TOKEN" https://YOUR-INVOKE-URL/query?q=test

Expected:

Valid response

✔ Authentication working

🪜 Step 5 — Load Test

Where: Terminal

kubectl run load-test --image=busybox --restart=Never -- \ /bin/sh -c "while true; do wget -q -O- http://rag-service; done"

🪜 Step 6 — Check Scaling

kubectl get pods -w

Expected:

  • Pods increase automatically

🪜 Step 7 — Check Logs

kubectl logs POD_NAME

Get POD_NAME using: kubectl get pods

🧠 If API is not working

Follow this order:

1. Check API Gateway

https://YOUR-INVOKE-URL/health
  • ❌ Not loading → API Gateway issue
  • ✔ Working → go next

2. Check ALB

kubectl get ingress
http://YOUR-ALB-DNS
  • ❌ Not working → ALB issue
  • ✔ Working → API Gateway issue

3. Check Pods

kubectl get pods
  • Should be Running
kubectl logs POD_NAME

4. Check Service

kubectl get svc

5. Check Auth

  • 401 → Token expired
  • Login again (Step 9)

🧠 Debug Flow

API Gateway → ALB → Pods

Find where it breaks and fix that layer.

🧠 Final Result

  • ✔ API working
  • ✔ Auth working
  • ✔ Scaling working
  • ✔ Logs visible

✔ System fully functional
