Step 6 — S3 + CloudFront (Frontend Hosting)

🧠 What you will do

You will:

  • Create a frontend file
  • Upload it to S3
  • Serve it using CloudFront

🪜 Step 1 — Create S3 Bucket

Where: AWS Console → S3 → Create bucket

  • Bucket name → any unique name
  • Region → ap-south-1
  • Uncheck "Block all public access"

✔ Bucket created

🪜 Step 2 — Create Frontend File (VERY IMPORTANT)

Where: Your local machine

Action:

  • Right-click → New File
  • Name it: index.html

Open the file and paste EXACTLY this:

<!DOCTYPE html> <html> <head> <title>AWS AI Ecosphere</title> </head> <body style="font-family: Arial; text-align: center; margin-top: 50px;"> <h1>AWS AI Ecosphere</h1> <p>Frontend connected successfully</p> </body> </html>

✔ File created correctly

🪜 Step 3 — Upload File to S3

Where: Open your S3 bucket

  • Click Upload
  • Select index.html
  • Click Upload

✔ File uploaded

🪜 Step 4 — Enable Static Website Hosting

Where: S3 → Bucket → Properties

  • Scroll to Static website hosting
  • Enable it
Index document: index.html

Copy the website endpoint URL shown

✔ S3 website ready

🪜 Step 5 — Create CloudFront Distribution

Where: AWS Console → CloudFront → Create distribution

  • Origin → Select your S3 bucket
  • Viewer protocol → Redirect HTTP to HTTPS

Click Create distribution

🪜 Step 6 — Get CloudFront URL

Where: Open your distribution

Copy:

https://dxxxxx.cloudfront.net

🪜 Step 7 — Test

Open in browser:

CloudFront URL

You should see:

  • AWS AI Ecosphere
  • Frontend connected successfully

✔ Frontend working

🧠 Note

This setup allows public access for learning. In production, S3 access is restricted and controlled via CloudFront.
