AWS AI Ecosphere

Step 8 — API Gateway (Public API Layer)

🧠 What problem are we solving?

ALB URL → direct access (not ideal)
API Gateway → controlled public API entry

API Gateway acts as the front door for your system. It receives requests and forwards them to your backend (ALB → Kubernetes).

🧠 Request Flow

User → API Gateway → ALB → Kubernetes → Response

🪜 Step 1 — Create API

Where: AWS Console → API Gateway

  • Click Create API
  • Select HTTP API
  • Click Build

Fill:

API name: ai-ecosphere-api

🪜 Step 2 — Add Integration (Connect ALB)

Where: Inside API → Integrations → Add integration

  • Integration type → HTTP

Enter ALB URL:

http://YOUR-ALB-DNS

Get ALB DNS from Step 4: kubectl get ingress

🪜 Step 3 — Create Route

Where: Routes → Create route

Method: ANY Path: /{proxy+}

This means: All incoming requests → forwarded to backend

🪜 Step 4 — Attach Integration

  • Select the route you created
  • Attach the ALB integration

🪜 Step 5 — Deploy API (Stage)

Where: Stages

A stage is a deployed version of your API.

Default stage: $default

✔ API deployed automatically

🪜 Step 6 — Get Invoke URL (IMPORTANT)

Where:

  • Top section of API page
  • Look for Invoke URL

Example:

https://abc123xyz.execute-api.ap-south-1.amazonaws.com

✔ This is your public API endpoint

🪜 Step 7 — Test API

Open in browser:

https://YOUR-INVOKE-URL/query?q=test

Expected:

Valid response from your app

🧠 What you achieved

✔ Public API created
✔ Requests routed to ALB
✔ Backend connected successfully

🧠 If it does not work

  • No response:
    Check ALB URL directly
  • 404 error:
    Check route /{proxy+}
  • Integration issue: Verify ALB DNS is correct
