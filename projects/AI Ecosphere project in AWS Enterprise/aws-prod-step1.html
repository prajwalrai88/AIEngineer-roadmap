AWS AI Ecosphere

Step 1 — VPC Setup (Network Foundation)

🧠 What problem are we solving?

No VPC → No network → Nothing runs ❌
With VPC → Controlled network → System works ✅

This step creates the network where your entire system (EKS, ALB, etc.) will run.

🧠 Key Concepts

VPC → Your private cloud network
Subnet → Segment inside VPC
Public Subnet → Has internet access
Private Subnet → Internal only
Internet Gateway → Connects VPC to internet
Route Table → Controls traffic flow

🪜 Step 1 — Create VPC

Where: AWS Console → Search "VPC"

  • Click Create VPC
  • Select VPC only

Fill:

Name: ai-ecosphere-vpc IPv4 CIDR: 10.0.0.0/16

✔ VPC created

🪜 Step 2 — Create Subnets

Where: VPC → Subnets → Create subnet

Create TWO subnets:

Public Subnet: Name: public-subnet CIDR: 10.0.1.0/24 Private Subnet: Name: private-subnet CIDR: 10.0.2.0/24

Public = internet-facing (ALB) Private = backend (EKS pods)

🪜 Step 3 — Create Internet Gateway

Where: VPC → Internet Gateways

  • Click Create Internet Gateway
  • Name → ai-ecosphere-igw
  • Attach to your VPC

✔ Internet access enabled

🪜 Step 4 — Create Route Table

Where: VPC → Route Tables

  • Create route table
  • Name → public-route-table
  • Associate with Public Subnet

Add route:

Destination: 0.0.0.0/0 Target: Internet Gateway

✔ Public subnet can access internet

🪜 Step 5 — Validate Setup

Check:

  • VPC exists
  • 2 subnets created
  • IGW attached
  • Route table linked to public subnet

✔ Network ready

🧠 What actually happened?

You created:

✔ Network boundary (VPC)
✔ Public access layer (subnet + IGW)
✔ Internal network (private subnet)
✔ Traffic routing rules

🧠 If something is not working

  • No internet:
    Check IGW attached
  • Subnet not public:
    Check route table association
  • Wrong CIDR: Ensure no overlap
