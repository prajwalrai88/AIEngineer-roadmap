P5 — IAM Setup (AWS Permissions)

🎯 Goal

Create a dedicated IAM user with proper permissions so you can safely interact with AWS using CLI and tools like EKS.

🪜 Step 1 — Open IAM Console

  • Login to AWS Console
  • Search for IAM in top search bar
  • Click IAM

🪜 Step 2 — Create IAM User

  • Click Users (left sidebar)
  • Click Create user
  • Enter username: 
    ai-ecosphere-user
  • Click Next

🪜 Step 3 — Set Permissions

  • Select: Attach policies directly
  • Search and select: 
    AdministratorAccess

⚠ This gives full access — OK for learning, NOT for production environments

🪜 Step 4 — Create Access Keys

  • After user is created → click the user
  • Go to Security credentials tab
  • Scroll to Access keys
  • Click Create access key
  • Select: 
    Command Line Interface (CLI)
  • Click Next → Create

⚠ Copy and save: 

Access Key ID
Secret Access Key

You will NOT be able to see the secret again

🪜 Step 5 — Configure AWS CLI

Run this in your terminal: 
aws configure
Enter values: 
AWS Access Key ID: YOUR_KEY
AWS Secret Access Key: YOUR_SECRET
Default region name: ap-south-1
Default output format: json

🪜 Step 6 — Validate Setup

Run: 
aws sts get-caller-identity
Expected output: 
{
  "UserId": "...",
  "Account": "...",
  "Arn": "arn:aws:iam::...:user/ai-ecosphere-user"
}

✔ IAM setup is correct

🧠 Explanation

  • IAM User → your identity in AWS
  • Access Keys → used by CLI/tools
  • Policies → define permissions

🚦 Checklist

  • ✔ IAM user created
  • ✔ Access keys generated
  • ✔ CLI configured
  • ✔ Validation command successful
