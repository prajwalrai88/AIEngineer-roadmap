Step 9 — Authentication + Monitoring

🧠 What you will do

  • Create Cognito authentication
  • Login and get JWT token
  • Secure your API

🪜 Step 1 — Create Cognito User Pool

Where:

  • AWS Console → Search "Cognito"
  • Click "User Pools"
  • Click "Create user pool"
  • Sign-in option → Email
  • Click Next → Next → Create

✔ User pool created

🪜 Step 2 — Create App Client

Where:

  • Open your User Pool
  • Go to "App integration"
  • Click "Create app client"
  • App type → Public client
  • Enable Authorization Code Grant
  • Callback URL:
    https://example.com

✔ App client created

🪜 Step 3 — Get Required Details

Copy from Cognito:

User Pool ID → ap-south-1_xxxxx Client ID → xxxxxxxxx Region → ap-south-1

🪜 Step 4 — Enable Hosted UI

Where:

  • User Pool → App integration
  • Scroll to Hosted UI
  • Create domain prefix:
    my-ai-ecosphere

✔ Hosted UI enabled

🪜 Step 5 — Create User

Where:

  • User Pool → Users
  • Click "Create user"
  • Email → your email
  • Password → set manually

🪜 Step 6 — Login and Get Token

Construct login URL:

https://YOUR_DOMAIN.auth.ap-south-1.amazoncognito.com/login? client_id=YOUR_CLIENT_ID& response_type=token& scope=email+openid& redirect_uri=https://example.com

Example:

https://my-ai-ecosphere.auth.ap-south-1.amazoncognito.com/login?client_id=abc123&response_type=token&scope=email+openid&redirect_uri=https://example.com

Steps:

  • Open URL in browser
  • Login with your user
  • After login, browser redirects

IMPORTANT:

Look at browser URL and find:

#id_token=eyJraWQiOi...

Copy everything after id_token=

✔ This is your JWT token

🧠 Token Expiry

JWT tokens expire after some time (usually ~1 hour).

If your API starts returning 401 Unauthorized again:

  • Repeat login step
  • Copy new token

✔ This is expected behavior

🪜 Step 7 — Configure API Gateway Auth

Where:

  • AWS Console → API Gateway
  • Select your API
  • Click "Authorization"

Create authorizer:

Type → JWT Issuer → https://cognito-idp.ap-south-1.amazonaws.com/YOUR_POOL_ID Audience → YOUR_CLIENT_ID

Attach:

  • Go to Routes → ANY /{proxy+}
  • Select this authorizer

🪜 Step 8 — Test Without Token

curl YOUR-INVOKE-URL/query?q=test

Expected:

401 Unauthorized

🪜 Step 9 — Test With Token

curl -H "Authorization: Bearer YOUR_ID_TOKEN" YOUR-INVOKE-URL/query?q=test

Expected:

Valid response

✔ Authentication working

🪜 Step 10 — Enable Logging

Where:

  • API Gateway → Stages → $default
  • Enable Access Logging
  • Enable Execution Logging

🪜 Step 11 — View Logs

Where:

  • AWS Console → CloudWatch → Logs
API-Gateway-Execution-Logs

✔ Logs visible
