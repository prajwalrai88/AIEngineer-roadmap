Step 7 — Docker

🎯 What are we doing?

Packaging backend into a container.

🎥 Learn This Concept

▶ Docker Explained Simply
  • Image vs container
  • Dockerfile basics
  • Running containers

🪜 Dockerfile

FROM python:3.11
WORKDIR /app
COPY . .
RUN pip install fastapi uvicorn
CMD ["uvicorn","app:app","--host","0.0.0.0","--port","8000"]

🪜 Run

docker build -t ai-app .
docker run -p 8000:8000 ai-app

✅ Expected

Backend running inside container
