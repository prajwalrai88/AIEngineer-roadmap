Step 4 — Document Ingestion

🎯 What are we doing?

We are loading a PDF document and converting it into structured text that can be processed by AI.

🧠 Why is this needed?

AI models cannot directly read PDF files. We must extract the text first, then convert it into embeddings in later steps.

🎥 Learn This Concept

▶ Watch: LangChain PDF Loader Tutorial

What you should learn:

  • How PDFs are loaded in LangChain
  • How text is extracted from documents
  • What Document objects represent

✔ Watch once, then come back and implement below

🪜 Step 1 — Install Dependencies

pip install langchain pypdf

🪜 Step 2 — Create ingestion.py

Create a file inside ingestion/ folder:

ingestion/ingestion.py

🪜 Step 3 — Add Code

from langchain.document_loaders import PyPDFLoader

loader = PyPDFLoader("sample.pdf")
documents = loader.load()

print("Loaded pages:", len(documents))

🔍 Code Explanation

  • PyPDFLoader → Loads PDF file
  • loader.load() → Extracts text
  • documents → List of pages
  • len(documents) → Number of pages

⚙️ How this fits in system

PDF → Text Extraction → (Next Step: Chunking & Embeddings)

🪜 Step 4 — Add Sample PDF

  • Download any PDF
  • Rename it to sample.pdf
  • Place inside ingestion/

🪜 Step 5 — Run Script

python ingestion.py

✅ Expected Output

Loaded pages: 5

✔ This confirms ingestion is working

❌ Common Errors

  • File not found → Check PDF name
  • Module not found → Reinstall packages
  • Wrong folder → Run from correct directory

🚦 Before Next Step

  • ✔ PDF loads successfully
  • ✔ Output shows page count
