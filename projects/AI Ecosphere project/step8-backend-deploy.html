Step 8 — Deploy Backend to Cloud

🎯 What are we doing?

We are deploying our FastAPI backend to a cloud platform so it can be accessed from anywhere.

🧠 Why is this needed?

Currently, your backend runs only on your local machine. Deployment makes it publicly accessible via a URL.

🎥 Learn This Concept

▶ Deploy FastAPI to Cloud (Render)
  • How deployment works
  • Connecting GitHub
  • Build & start commands
  • Environment variables

✔ Watch once, then follow steps below

🪜 Step 1 — Push Code to GitHub

git init
git add .
git commit -m "initial commit"
git remote add origin https://github.com/your-username/repo.git
git push -u origin main

🪜 Step 2 — Create Account on Render

  • Go to https://render.com
  • Login using GitHub

🪜 Step 3 — Create Web Service

  • Click "New → Web Service"
  • Select your repository

🪜 Step 4 — Configure Deployment

Build Command:
pip install -r requirements.txt

Start Command:
uvicorn app:app --host 0.0.0.0 --port 10000

🪜 Step 5 — Add Environment Variables

OPENAI_API_KEY=your_key
PINECONE_API_KEY=your_key

🪜 Step 6 — Deploy

  • Click "Create Web Service"
  • Wait 2–5 minutes

✅ Expected Output

Your backend will be live at:

https://your-app.onrender.com/health

{"status":"ok"}

✔ Backend is now deployed

⚙️ How this fits in system

Frontend → Cloud Backend → AI Processing → Response

❌ Common Errors

  • Build failed → missing requirements.txt
  • App not starting → wrong start command
  • API not working → missing env variables
