Step 5 — FastAPI Backend

🎯 What are we doing?

We are building a backend API that will handle user requests and connect to our AI pipeline.

🧠 Why is this needed?

The frontend cannot directly interact with AI logic or data pipelines. We need a backend to process requests, run AI logic, and return responses.

🎥 Learn This Concept

▶ Watch: FastAPI Full Tutorial Playlist

What you should learn:

  • How APIs work
  • Creating routes (GET, POST)
  • Running a FastAPI server
  • Understanding request → response flow

✔ You don’t need to watch everything — focus on basics + endpoints

🪜 Step 1 — Install Dependencies

pip install fastapi uvicorn

🪜 Step 2 — Create Backend File

backend/app.py

🪜 Step 3 — Add Code

from fastapi import FastAPI

app = FastAPI()

@app.get("/health")
def health():
    return {"status": "ok"}

@app.get("/")
def home():
    return {"message": "AI Ecosphere Backend Running"}

🔍 Code Explanation

  • FastAPI() → Creates API app
  • @app.get() → Defines endpoint
  • /health → Used for system checks
  • Return JSON → API response

🪜 Step 4 — Run Server

uvicorn app:app --reload

✅ Expected Output

Open browser:

http://127.0.0.1:8000/health

{"status":"ok"}

✔ Backend is working

⚙️ How this fits in system

Frontend → Backend API → AI Processing → Response

❌ Common Errors

  • Module not found → install dependencies
  • Port already used → change port
  • Server not starting → check file name
