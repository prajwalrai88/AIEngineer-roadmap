Step 9 — Deploy Frontend

🎯 What are we doing?

We are deploying our frontend UI so users can access it from the internet.

🧠 Why is this needed?

Your frontend currently runs only on your local machine. Deployment makes it publicly accessible.

🎥 Learn This Concept

▶ Deploy Next.js App (Vercel)
  • How Vercel deployment works
  • Connecting GitHub
  • Environment variables

✔ Watch once, then follow steps below

🪜 Step 1 — Push Frontend to GitHub

cd frontend

git init
git add .
git commit -m "frontend deploy"
git remote add origin https://github.com/your-username/frontend-repo.git
git push -u origin main

🪜 Step 2 — Go to Vercel

  • Open https://vercel.com
  • Login using GitHub

🪜 Step 3 — Import Project

  • Click "Add New → Project"
  • Select your frontend repo

🪜 Step 4 — Add Backend URL

Connect frontend to backend deployed in Step 8. 

NEXT_PUBLIC_API_URL=https://your-backend.onrender.com

🪜 Step 5 — Update API Call

fetch(`${process.env.NEXT_PUBLIC_API_URL}/health`)

🪜 Step 6 — Deploy

  • Click "Deploy"
  • Wait 1–2 minutes

✅ Expected Output

Your app will be live at:

https://your-app.vercel.app

✔ UI loads successfully ✔ Connected to backend

⚙️ How this fits in system

User → Frontend (Vercel) → Backend (Render) → AI → Response

❌ Common Errors

  • API not working → wrong backend URL
  • Build failed → check logs
  • No response → backend not deployed

🚦 Before Final Step

  • ✔ Frontend deployed
  • ✔ URL accessible
  • ✔ Backend connected
